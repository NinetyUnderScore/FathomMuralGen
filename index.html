Frequently Asked Questions

Can you add [this feature]

Idk probably, send a message or ping _90_ in the thread for this tool on the Fathom Discord server.

What font is used?

All murals use the Legacy font due to being significantly larger than the other fonts meaning only 80 characters are needed to fill the page.

The generator always opens its output string with <font face='Legacy'> to ensure this font is applied. If a nested color tag has to re-declare the face after a close, it will use <font face='Legacy' color='…'> automatically.

How the character limit works

Papers in Fathom have a hard limit of 400 characters of rich text. Every mural string must fit within this budget. The breakdown is:

<font face='Legacy'> opening = 19 chars
@ × 80 tiles = 80 chars
Each color change (</font><font color='#xyz'>) = 26 chars
First color (merged into the opening tag as an attribute) = 19 chars (no extra cost beyond the open)

With 80 tiles and the opening tag already consuming 99 characters, a full page leaves room for approximately 11 color changes before hitting the 400-character ceiling.

How optimizations work

First-tile color merge

If only one color tag appears on the entire paper and it's on tile 1, it's merged directly into the opening <font face='Legacy'> as a color attribute instead of being a separate tag. This saves 7 characters.

No space between attributes

Roblox's rich text parser doesn't require a space between consecutive tag attributes, so face='Legacy'color='#fff' is valid. The generator never adds that space, saving 1 character per combined tag.

Minimal font re-declaration

After a </font> closes a color tag, the Legacy face is only re-declared in the next opening tag if the stack no longer has a face tag active. If Legacy is already set by a parent tag still open, the new tag is just <font color='…'>.

No-op close drops

A </font> on a tile that has nothing to close is dropped from the output as it would waste 7 characters and do nothing visually.

Redundant reopen elimination (⚠)

If a tile closes a color and the very next open tag would reopen the exact same color, the entire close+reopen pair is eliminated. The tile is flagged with ⚠ in the editor. This saves 26 characters at the cost of the one tile's color being "inherited" from the parent.

Unclosed trailing tag

The outermost <font face='Legacy'> (as well as the last color tag) is never closed at the end of the string. Roblox does not require tags to be closed and leaving it open saves 7 characters.

Image importer: how color regions are chosen

The image importer solves an optimization problem to decide where to place color boundaries. Because each color change costs 26 characters, you can only afford around 11 of them per page. The solver finds the best placement by working through all 80 tiles left to right, tracking the best possible color error score for every "characters spent so far" amount at each position, discarding any path that's already beaten by another path that reached the same state.
